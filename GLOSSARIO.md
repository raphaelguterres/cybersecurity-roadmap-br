# Glossário essencial de cibersegurança

| Termo | Resumo acessível |
| --- | --- |
| Ativo | Algo de valor para a organização que merece proteção. |
| Ameaça | Fonte ou evento que pode causar dano. |
| Vulnerabilidade | Fragilidade explorável em uma condição. |
| Exposição | Situação na qual um ativo pode ser alcançado ou afetado. |
| Risco | Possibilidade de consequências adversas sob incerteza. |
| CIA | Confidencialidade, integridade e disponibilidade. |
| Autenticação | Verificação de identidade. |
| Autorização | Decisão sobre ações permitidas a uma identidade. |
| MFA | Uso de mais de um fator de autenticação. |
| Menor privilégio | Conceder apenas o acesso necessário. |
| Hardening | Redução da superfície de exposição por configuração e controle. |
| Telemetria | Dados coletados para observar comportamentos e estado. |
| Log | Registro de evento produzido por sistema ou aplicação. |
| IOC | Indicador que pode sinalizar atividade maliciosa. |
| TTP | Táticas, técnicas e procedimentos observáveis. |
| SIEM | Plataforma para agregar, buscar, correlacionar e analisar eventos. |
| SOC | Equipe/função de monitoramento, análise e resposta a eventos. |
| EDR | Ferramenta de detecção e resposta focada em endpoint. |
| IDS / IPS | Sistemas que detectam / podem bloquear tráfego ou ações suspeitas. |
| Falso positivo | Alerta emitido para condição que não corresponde ao cenário de interesse. |
| Falso negativo | Condição de interesse que passou sem detecção. |
| MITRE ATT&CK | Base de táticas e técnicas observadas em adversários. |
| Threat hunting | Busca estruturada, orientada a hipóteses, por sinais de ameaça. |
| AppSec | Segurança aplicada a software e ao ciclo de desenvolvimento. |
| SAST / DAST | Análise estática de código / análise dinâmica de aplicação. |
| SCA | Análise de componentes e dependências de software. |
| SSDLC | Ciclo de desenvolvimento com práticas de segurança integradas. |
| DFIR | Forense digital e resposta a incidentes. |
| Cadeia de custódia | Registro de posse e integridade de evidências. |
| IAM | Gestão de identidades e acessos. |
| GRC | Governança, riscos e conformidade. |
| CVE | Identificador público de vulnerabilidade registrada. |
| CVSS | Sistema de pontuação de gravidade de vulnerabilidades. |
| CVE ≠ exploração | Existência de CVE não implica risco real em todo contexto. |
| Contenção | Ações para limitar impacto de incidente. |
| Recuperação | Restauração e validação de serviços após evento. |
| TLP | Convenção de compartilhamento de informações por sensibilidade. |

Sugestões e correções são bem-vindas via PR; sempre inclua referências.
