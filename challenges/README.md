# Desafios da comunidade

Esta coleção é um **catálogo de atividades**, não uma plataforma de execução de código remoto. Escolha um desafio, resolva em laboratório permitido e escreva sua própria análise. O dashboard registra conclusão autodeclarada; não avalia o trabalho.

## Seis desafios iniciais

| ID | Desafio | Evidência / critério |
| --- | --- | --- |
| CH01 | 30 minutos de análise de tráfego | Desenho DNS/TLS, 3 metadados da sua máquina, sem PCAP publicado |
| CH02 | Hipótese SOC em um parágrafo | Sintomas, 2 explicações alternativas e dados adicionais necessários |
| CH03 | Um controle, três testes | Teste positivo, negativo e regressão para autorização em app fictícia |
| CH04 | IAM para equipe fictícia | Matriz de permissões, responsável e plano de revogação |
| CH05 | Detecção mensurável | Hipótese, campos, falso positivo e plano de rollback para lab próprio |
| CH06 | Incidente sintético documentado | Timeline, incertezas, contenção planejada e resumo executivo |

## Regras

1. Não execute testes contra terceiros sem autorização expressa.
2. Use dados fictícios e serviços próprios/isolados.
3. Inclua versão de ambiente, resultado observado, limitações e referências.
4. Não compartilhe exploit utilizável contra serviço externo, credenciais ou dados de vítimas.
5. Envie sugestões novas por [Issue](../.github/ISSUE_TEMPLATE/sugerir-lab.yml) ou PR.

## Desafio comunitário rotativo

A cada ciclo, o mantenedor **poderá** destacar um desafio via Discussions e convidar comentários/revisões; ainda não há agenda automática de desafios. Não há ranking, premiação ou certificação nesta versão.
