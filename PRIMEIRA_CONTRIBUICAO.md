# Sua primeira contribuição em 5, 15 ou 60 minutos

**Não precisa saber programar para contribuir.** Há trabalho editorial, educativo, de acessibilidade e técnico.

## Se você tem 5 minutos

1. Escolha um guia que está estudando.
2. Se encontrar uma explicação confusa ou um link quebrado, busque a fonte original.
3. Abra uma [Issue de melhoria](https://github.com/raphaelguterres/cybersecurity-roadmap-br/issues/new/choose) com link para o arquivo e proposta concreta.
4. Informe **o que conseguiu verificar** e o que permanece incerto.

## Se você tem 15 minutos

1. Leia [CONTRIBUTING.md](CONTRIBUTING.md) e [Código de Conduta](CODE_OF_CONDUCT.md).
2. Localize uma [Issue para iniciantes](https://github.com/raphaelguterres/cybersecurity-roadmap-br/labels/good%20first%20issue).
3. Faça fork do repositório e edite um arquivo Markdown.
4. Abra um PR pequeno, explicando a correção e a fonte consultada.
5. Responda aos comentários de revisão com respeito. Não há obrigação de ficar disponível em tempo real.

## Se você tem 60 minutos ou mais

- **Revisão técnica:** execute um laboratório **em ambiente permitido**, compare o observado com o guia, descreva resultado positivo e negativo.
- **Nova fonte:** proponha um link oficial verificável, categoria, idioma, acesso e data da consulta.
- **Acessibilidade:** melhore navegação, headings, descrição de imagens e clareza textual.
- **Dev:** escreva teste, simplifique interface, revise dependências e segurança do dashboard.
- **Comunidade:** proponha um desafio ou um plano assíncrono de estudos com entregas pequenas.

## Modelo de primeira Issue

```md
**Arquivo/link afetado:** ...
**O que observei:** ...
**Como reproduzir ou verificar:** ...
**Fonte original (se aplicável):** ...
**Mudança pequena que sugiro:** ...
**Há dados privados?** Não.
```

## Critérios de um bom PR

- Uma mudança com propósito único e arquivo(s) identificados.
- Nenhum segredo, dado pessoal ou conteúdo sem licença.
- URL de fonte e contexto, quando fizer afirmações técnicas.
- Critérios de aceitação explícitos, inclusive o que não foi testado.
- Boa disposição para revisão e correções.
- Checagens do GitHub Actions aprovadas antes de incorporar à main.

**Autoria sempre reconhecida nos commits/PRs.** Contribuir não gera vínculo trabalhista, remuneração nem direito a certificado. Para dúvidas, use [Discussions](https://github.com/raphaelguterres/cybersecurity-roadmap-br/discussions).
