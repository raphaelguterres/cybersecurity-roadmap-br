# 02 — Programação, Git e automação

**Objetivo:** ganhar autonomia para tratar dados, testar hipóteses e automatizar tarefas repetitivas.

## Base recomendada

- **Python:** tipos, arquivos, JSON, CSV, exceções, bibliotecas padrão e testes.
- **Shell:** Bash ou PowerShell para navegação, processos e logs locais.
- **Git:** branches, commits legíveis, PRs, revisão e conflitos.
- **Markdown:** README, procedimentos reproduzíveis e tabelas.
- **Segurança de código:** validação de entrada, manejo de exceções e ausência de segredos no repositório.

## Exercício inicial

Crie um programa que leia eventos fictícios de autenticação de um arquivo local, conte falhas por usuário **fictício** e gere CSV de resumo. Adicione pelo menos 3 testes: arquivo vazio, evento malformado e evento válido.

## Critérios para avançar

- [ ] Não incluo credenciais, tokens, cookies ou logs reais em commits.
- [ ] Documento pré-requisitos, execução, resultado esperado e limitações.
- [ ] Consigo explicar e testar cada linha do meu script.
- [ ] Uso Git para guardar versões e receber revisão.
