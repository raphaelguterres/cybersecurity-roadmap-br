# Curadoria de vídeos — desenvolvimento, carreira e engenharia

Esta área reúne fontes originais de criadores brasileiros e propõe **exercícios próprios** para consolidar aprendizado. Não copiamos falas extensas, transcrições, materiais pagos ou vídeos. As interpretações editoriais são do projeto. **Não existe parceria, patrocínio nem endosso** dos criadores.

## Método recomendado — do vídeo à evidência

Para qualquer vídeo que você **assistir de fato**:

- [ ] Salvar URL, título, autor, data de publicação e data de consulta.
- [ ] Distinguir opinião, relato pessoal, dado e recomendação técnica.
- [ ] Registrar em **palavras próprias** 3 aprendizados relevantes.
- [ ] Validar o aspecto técnico em documentação primária.
- [ ] Executar microexercício seguro e documentar resultado real.
- [ ] Marcar incertezas e revisitar conteúdos que envelhecem.

~~~

Não adicione um vídeo apenas por estar em tendência: confira URL e autoria. A curadoria deve crescer **por revisão humana**, não por promessas de ingestão automática de canais ou coleta não autorizada de transcrições.
